黑潮 DNS 3.3.7：依 padavan-tw 在 Newifi D3 驗證 3.3.6 的結果，修正每日評測的一個誤判與兩處顯示。程式與設定格式跟 3.3.6 相同，不用改設定。

3.3.6 的路徑檢查在 D3 上全部符合預期：一開機就認出「一般 DNS 被路由器上的黑潮（3.3.6）接走」，IPv4 / IPv6 的判斷正確；評測不再測 467 台被接走的一般 DNS，時間從約 30 分鐘降到 23 分鐘；11-18 那 15 台被誤判的加密 DNS 沒有再被記可疑；沒有 IPv6 時 `sendmsg AddrNotAvailable` 從一晚 8 次降到 0 次。

## 修正

- **多家 CDN 的網域，「連不上」不再記可疑**：
  - 狀況：`cdn-mum.alibabachengdun.com` 由很多家 CDN 提供，同一題已經有 39 個規則外但憑證有效的回答，`sea01`、`sjc02.dnscry.pt` 卻因為連不上（TIMEOUT）被記了一天可疑。
  - 修法：規則外的回答裡已經有 2 家以上不同業者憑證有效時，這個網域就算「多家 CDN」，上面的「連不上」今天不用，但不記可疑天數。憑證不符的照舊判定汙染。
  - 原本「連不上」就要在 3 個不同日期都發生才會進永久黑名單，同一個網域底下的多個節點（例如 dnscry.pt 的各地節點）在「互相獨立」的計算裡也本來就算同一家。這次是讓這種網域連第一天都不記。
- **業者名稱查不到 AS 編號時的顯示**：評測記錄（`judge.log`）與黑名單註解原本會出現 `SHERNET__` 這種半截的名稱，改成「SHERNET（查不到 AS 編號）」。`upstreams.json` 的 `owner` 格式不變。
- **路徑檢查的提醒少一個空格**：「一般 DNS被…」改成「一般 DNS 被…」（狀態頁、`/api/status` 的 `warnings`、系統記錄）。

**OpenWrt**：在路由器執行 `cat /etc/openwrt_release`，依 `DISTRIB_RELEASE`（OpenWrt 版本）與 `DISTRIB_ARCH`（套件架構）下載 `kuroshio-openwrt-<版本>-<架構>.zip`。

OpenWrt 24.10 用 `-24.10-` 的（.ipk），25.12 以後用 `-25.12-` 的（.apk）。不知道選哪個：[選硬體](https://github.com/candy999/kuroshio-dns/blob/main/docs/hardware.md)。

壓縮檔裡有 `kuroshio`、`luci-app-kuroshio` 與一鍵安裝腳本：解壓後把資料夾傳到路由器，執行 `sh install.sh`。腳本會先檢查架構與版本，不符合就告訴你該下載哪一個。裝好後到 LuCI「服務 → 黑潮 DNS」確認設定、按「啟用」。

**Windows 10 / 11**：`kuroshio-windows-x86_64.zip`，單一執行檔，不需要另外安裝 Visual C++ 執行階段。

**Docker**：`docker pull ghcr.io/candy999/kuroshio-dns:3.3.7`，見 [Docker 使用說明](https://github.com/candy999/kuroshio-dns/blob/main/docs/docker.md)。

**其他 Linux、第三方路由器韌體**：`kuroshio-linux-<CPU>.tar.gz`（執行檔＋`data/`），見 [移植指南](https://github.com/candy999/kuroshio-dns/blob/main/PORTING.md)；只要執行檔的話是 `kuroshio-<CPU>`。`SHA256SUMS` 是所有檔案的雜湊值。

**原始碼**：`kuroshio-dns-3.3.7-source.tar.xz`（這個版本的原始碼加上全部依賴套件，可以完全離線編譯；雜湊值在 `SHA256SUMS`）。

## 從 3.3.6 升級

- **OpenWrt**：下載同一個架構的新壓縮檔，解壓後執行 `sh install.sh`，直接覆蓋升級。
- **Windows**：停止黑潮 DNS（cmd 視窗輸入 `quit`，或 `kuroshio.exe service stop`），用新的 `kuroshio.exe` 與 `data\` 取代舊的，再啟動。
- **Docker**：`docker compose pull && docker compose up -d`（或 `docker pull ghcr.io/candy999/kuroshio-dns:3.3.7`）。
- **其他 Linux、第三方韌體**：執行檔與 `data/` 一起換；用 UCI 文字設定檔的，升級後執行一次 `kuroshio uci-migrate <UCI 檔>`。

已經被記了一天可疑的上游不用處理：可疑紀錄 30 天沒再發生就會自動忘掉，這一版之後同樣的狀況也不會再記。
