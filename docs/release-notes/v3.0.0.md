黑潮 DNS 3.0 是第一個正式版：從 2.x（Node.js）完整改寫成 Rust 單一執行檔，不需要任何執行環境。

## 下載哪一個

**OpenWrt**：在路由器執行 `cat /etc/openwrt_release`，依 `DISTRIB_RELEASE`（OpenWrt 版本）與 `DISTRIB_ARCH`（套件架構）下載 `kuroshio-openwrt-<版本>-<架構>.zip`。

| 平台 | 常見晶片 | 檔名結尾 |
|---|---|---|
| 64 位元 ARM | MediaTek Filogic（MT7981 / MT7986 / MT7988）、MT7622、Qualcomm IPQ807x / IPQ60xx / IPQ50xx、樹莓派 3 | `aarch64_cortex-a53` |
| | Rockchip RK3328 / RK3399 / RK3568 / RK3588（NanoPi R2S～R6S） | `aarch64_generic` |
| | 樹莓派 4、Marvell Armada 7K / 8K | `aarch64_cortex-a72` |
| | 樹莓派 5 | `aarch64_cortex-a76` |
| 32 位元 ARM | Qualcomm IPQ4018 / IPQ4019、Allwinner H3 | `arm_cortex-a7_neon-vfpv4` |
| | Marvell Armada 385（Linksys WRT 系列） | `arm_cortex-a9_vfpv3-d16` |
| | Qualcomm IPQ806x（Netgear R7800 等） | `arm_cortex-a15_neon-vfpv4` |
| MIPS | MediaTek MT7621 / MT7620 / MT7628（小端序） | `mipsel_24kc` |
| | Qualcomm Atheros、Lantiq（大端序） | `mips_24kc` |
| x86 | 軟路由小主機、虛擬機 | `x86_64` |

OpenWrt 24.10 用 `-24.10-` 的（.ipk），25.12 以後用 `-25.12-` 的（.apk）。不知道選哪個：[選硬體、選套件](https://github.com/candy999/kuroshio-dns/blob/main/docs/hardware.md)。

壓縮檔裡有 `kuroshio`、`luci-app-kuroshio` 與一鍵安裝腳本：解壓後把資料夾傳到路由器，執行 `sh install.sh`。腳本會先檢查架構與版本，不符合就告訴你該下載哪一個。裝好後到 LuCI「服務 → 黑潮 DNS」確認設定、按「啟用」。

**Windows 10 / 11**：`kuroshio-windows-x86_64.zip`，單一執行檔，不需要另外安裝 Visual C++ 執行階段。

**其他 Linux**：`kuroshio-<CPU>` 靜態執行檔。`SHA256SUMS` 是所有檔案的雜湊值。

## 重點功能

- **把連線帶回台灣**：CDN（Cloudflare、Fastly、CloudFront、Azure、Gcore…）的回應換成實際用 HTTPS 驗證過的台灣節點；ECS、跨 CDN、IPv6 節點、每小時抽樣複驗。
- **自動挑上游**：每天實測公共 DNS 的速度與汙染（用網站憑證判斷答案有沒有被竄改），並行查詢。
- **過濾**：廣告、遙測、惡意 / 詐騙，內建 165 反詐騙等台灣清單，自訂規則永遠優先。
- **加密 DNS 伺服器與上游**：DoT、DoH（HTTP/2）、DoH3、DoQ；DDR 與 DNR（OpenWrt）讓裝置自動升級成加密連線。DoH 可以用 443 以外的埠。
- **預設只開放台灣**：依 ISP 分組的台灣 IP 清單，台灣 IP 清單每月在你的裝置上自己產生，不依賴任何中央伺服器；OpenWrt 在核心層丟封包。
- **好友互助**：好友邀請碼，貼上就自動配對；點對點同步、只交換網域雜湊、資料一律本機驗證後才使用。
- **共用儀表板**：公開頁、Windows 設定頁、LuCI 同一套圖表；OpenWrt 不用開公開頁也看得到。
- **低階路由器友善**：沒有硬體等級，記憶體與 Flash 依系統保留量動態使用與讓出；最低保留純 DNS 轉發，當掉 1 秒內重啟，OpenWrt 重新啟動期間由 dnsmasq 暫時接手。Flash 寫入壓縮、分片，學到的資料最久 24 小時一定存檔。
- **Windows**：服務、設定頁、cmd 互動指令；跟 IIS 共用 443（HTTP.sys 或反向代理，憑證自動匯入與綁定）。
- **備份與換機**：學習資料匯出 / 匯入；從 2.x（candydns）升級時自動帶入設定、規則、憑證、社群金鑰。

## 行為改變（從 2.x 升級請看）

- **預設只開放台灣**：DoH / DoT / DoQ / DoH3 與公開頁預設只讓台灣 IP 加上區網連入。人在國外或用出口在國外的 VPN 的親友，請在「連線來源」把他們的 IP 加進允許清單，或改成「全開放」。
- **沒有硬體等級**：舊設定的 `profile` / `tier` 照樣讀得進來、不再使用。

## 已知限制

- DNSCrypt 不支援（伺服器都同時提供 DoH / DoT）。
- 以下還沒有在實機上驗證，只在 CI（QEMU、OpenWrt 容器、GitHub 的 Windows 機器）測過：MIPS 實機的記憶體用量、OpenWrt 實機的 nftables 規則與 dnsmasq 備援切換、兩台路由器的好友配對、Windows 11 開啟 HTTP.sys 的 HTTP/3。遇到問題歡迎回報。
