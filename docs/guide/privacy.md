# 隱私與安全

[← 使用者指南](README.md)

黑潮沒有帳號、沒有官方伺服器、沒有遙測。

## 黑潮連到哪裡

執行期間只連：

- 你設定的上游（與每日評測的候選）；
- CDN 驗證目標（驗證台灣節點用的 HTTPS 連線）；
- 你加的好友；
- 產生台灣 IP 清單用的公開資料來源（RIR、RIPEstat）；
- 過濾清單的網址、ACME 與 DDNS（有開的話）。

## 要注意的地方

- **惡意網站探測**：每日評測會查一些還在活動的惡意網域（只查 DNS、不連線，`judge.log` 不寫出網域）；線路上的資安設備可能把這台記成「有裝置中毒」。企業或學校網路建議關掉 `benchmark.malwareProbe`，見[每日評測](upstreams.md#惡意網站探測benchmarkmalwareprobe)。
- **好友之間只交換網域雜湊**；ISP 群組（`community.shareIspGroup`）預設不送，開了也只送群組、不送 IP，只給已經是好友的對象。見[好友互助](community.md)。
- **公開頁**：網站排行是匿名的，對外開放時只列出至少 2 位使用者共同造訪的網站；詳細頁不顯示本機路徑，上游只顯示主機名稱。見[公開頁與儀表板](dashboard.md)。
- **完整備份含私鑰**，不要給別人；分享檔不含身分與金鑰。見[備份](backup.md)。

## 管理介面

| 項目 | 做法 |
|---|---|
| 監聽位址 | 預設只聽本機（`admin.host` 是 `127.0.0.1`） |
| 開放給區網 | `admin.host: "0.0.0.0"`（Docker 的預設設定）時一定要開登入 |
| DNS rebinding | 只接受用本機名稱、IP 位址或 `admin.allowedHosts` 裡的名稱開，別的網站沒辦法借你的瀏覽器操作設定頁 |
| 會改東西的動作 | 只收 POST，跨站請求一律拒絕 |
| 密碼與 token | 不送到瀏覽器；日誌會遮蔽密碼與 token |
