一路開發下來的特點

一般 DNS 只負責把網址翻成 IP，黑潮 DNS 會多做很多事。

加密 DNS 全支援

手機、電腦到這台伺服器全程加密，電信業者與公共 Wi-Fi 看不到你查了哪些網站，也沒辦法竄改結果。支援 DDR，裝置能自動發現加密連線；EDNS Padding 讓封包長度也透露不了內容。

  • DoH（HTTP/1.1・HTTP/2）
  • DoH3（HTTP/3）
  • DoT
  • DoQ
  • DDR 自動發現
  • EDNS Padding

CDN 走台灣節點

Cloudflare、CloudFront 等常把台灣用戶導去國外機房。這裡辨識各大 CDN 之後，換成台灣或最近的節點；每個網站都先驗證能正常運作才換。

  • 逐站驗證
  • ECS
  • 跨 CDN 備援
  • IPv6 永久節點
  • 尖峰時段加權

多個上游一起問

同時詢問多個上游 DNS，合併答案後實測每個 IP 的連線速度，給你最快的那組；上游名單每天自動評測一次。

  • 並行查詢
  • IP 測速
  • 每日上游評測

聰明的快取

常用的網址在過期前自動更新，開機後先把熱門網域預熱好；上游暫時斷線時，先回上一次的答案，網路不會整個停擺。

  • 自適應預取
  • 開機預熱
  • 斷線先回舊資料

擋廣告、遙測與詐騙

在 DNS 層直接擋掉廣告、遙測追蹤，以及釣魚、詐騙與散播惡意程式的網站，App 和網頁都有效。自訂規則永遠優先，被誤擋的網站可以自己放行。

  • 廣告
  • 遙測
  • 詐騙與惡意網站
  • 自訂規則優先

好友社群共享

架設黑潮 DNS 的好友之間，可以互相分享台灣節點、網站驗證結果與評測選出的上游。資料有簽章驗證，網站只分享網域的雜湊值；收到的資料只當參考，一律先在本機驗證過才會使用。

  • 簽章驗證
  • 只分享網域雜湊
  • 本機驗證後才用

預設不記錄

預設不記錄查詢內容。這一頁的公開統計只有匿名的彙總：網站排行只有網站名稱與次數，看不到是誰造訪，也沒有 IP。

  • 不記錄查詢內容
  • 匿名彙總

小台路由器也能跑

128 MB 記憶體的路由器就能執行。依硬體自動分級，調整快取大小與功能；資料寫入有節制，保護 Flash 的壽命。

  • 128 MB 記憶體
  • 依硬體自動分級
  • 保護 Flash 寫入壽命

OpenWrt 與 Windows

路由器上用 OpenWrt 的 LuCI 介面管理；Windows 上可以裝成系統服務，有網頁設定頁，也能跟 IIS 共存。兩邊跑的是同一份核心。

  • OpenWrt（LuCI）
  • Windows 服務
  • 設定頁
  • IIS 共存

為什麼用 Rust 重寫

3.0 版把整個伺服器從 Node.js 改寫成 Rust：功能一樣，更省資源、更穩定，也更容易裝進小台的路由器。

01

單一執行檔

不需要另外安裝 Node.js 等執行環境，一個檔案複製過去就能跑，更新也只是換掉這個檔案。

02

記憶體安全

編譯器在編譯時就擋掉緩衝區溢位、use-after-free 這類常見的安全漏洞，對 24 小時對外開放的服務特別重要。

03

沒有垃圾回收停頓

記憶體用完就立刻釋放，不會因為回收記憶體突然卡一下，回應時間穩定。

以 tokio 非同步執行，大量同時進來的連線平均分給每一顆 CPU 核心處理。

選擇你的裝置。設定只要做一次，之後連 Wi-Fi 或行動網路都會自動使用。

需要 iOS / iPadOS 14 以上。請用 Safari 開啟這個頁面。

常見問題

某個網站或 App 打不開怎麼辦？

先依上面的方式暫時停用，確認是不是 DNS 造成的。如果停用後就正常，請把網址告訴我，我會把它加進白名單。

為什麼有些廣告還是會出現？

DNS 只能擋「專門放廣告的網域」。YouTube 影片廣告、Facebook / Instagram 動態裡的廣告，和正常內容來自同一個網域，DNS 擋不掉。

「拉回台灣」是怎麼算的？

每次 CDN 網站的查詢，都會同時看其他公共 DNS 給的答案。如果它們會把你送去國外機房，而這裡給的是台灣節點，就算一次成功拉回；縮短的毫秒數是伺服器實測兩邊連線時間的差距。

出國可以用嗎？

可以，加密和擋廣告照常有效。不過「走台灣節點」是為在台灣使用設計的，人在國外時部分網站會被導回台灣反而變慢；長時間出國建議先停用。

連飯店、機場 Wi-Fi 時登入頁面跳不出來？

少數公共 Wi-Fi 的登入頁需要使用當地的 DNS。暫時停用、完成登入後再開回來即可。

我也想架一台自己的，可以嗎？

可以。黑潮 DNS 是開放原始碼軟體（GPL-3.0-or-later），可以裝在 OpenWrt 路由器或 Windows 電腦上，原始碼網址在頁尾的「關於」。架好之後，你的伺服器也會有一個寫著你自己網址的分享頁。

你看得到我上了什麼網站嗎？

伺服器為了除錯會即時顯示查詢，但不會寫入硬碟保存。首頁統計只有匿名彙總：排行只有網站名稱與次數，看不到是誰造訪、也沒有 IP（架設的人可以設定只列出多位使用者共同造訪的網站）。
