Windows 使用提醒
  • 路由器埠轉發：除了 TCP 443、TCP 853，也要加 UDP 443（DoH3）與 UDP 853（DoQ）。很多人只轉了 TCP，DoH3 / DoQ 就連不進來。
  • 防火牆：用「以系統管理員身分執行」開啟命令提示字元，執行一次 kuroshio.exe setup，會加入 Windows 防火牆規則（只加實際開啟的協議）、網址登記與憑證綁定。之後一般權限也能跑全部功能。
  • 第一次監聽時 Windows 可能跳出防火牆詢問，按「允許」即可（執行過 setup 就不會跳）。
